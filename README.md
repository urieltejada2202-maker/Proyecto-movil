# ProjectWizard

**ProjectWizard** es una aplicación móvil multiplataforma desarrollada en Ionic y Angular, diseñada para optimizar la gestión de tareas, control de proyectos y organización diaria. Cuenta con una interfaz moderna basada en diseño Neo-Brutalismo, soporte multimedia completo y la capacidad de operar de forma fluida tanto en línea como sin conexión.

## Tecnologías Utilizadas

* **Framework Principal:** Ionic y Angular
* **Motor Nativo / Puente:** Capacitor
* **Plugins de Capacitor:** 
  * `@capacitor/camera` (Captura y selección de multimedia)
  * `@capacitor/filesystem` (Gestión y guardado de archivos locales)
  * `@capacitor/network` (Monitoreo de estado de red en tiempo real)
* **Almacenamiento Local:** `@ionic/storage-angular` y `localforage`
* **Estilos:** CSS / SCSS con diseño Neo-Brutalismo personalizado

## Instrucciones de Instalación y Ejecución

Para clonar y poner en marcha el proyecto de manera local, ejecuta los siguientes comandos en tu terminal:

```bash
# 1. Clonar el repositorio
git clone [https://github.com/urieltejada2202-maker/proyecto-movil.git](https://github.com/urieltejada2202-maker/proyecto-movil.git)

# 2. Entrar a la carpeta del proyecto
cd proyecto-movil

# 3. Instalar las dependencias necesarias
npm install

# 4. Iniciar el servidor de desarrollo
ionic serve
